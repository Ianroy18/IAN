## Installation Steps Process

1. clone this repo
2. cd ./repo name
3. npm install
4. npm run dev

## Deploying to GitHub Pages
1. Push the project to the `main` branch of `Ianroy18/IAN`.
2. From the project directory, run `npm run deploy`.
3. In the repository's **Settings → Pages**, select **Deploy from a branch**, then choose the `gh-pages` branch and `/(root)` folder.
4. Open `https://ianroy18.github.io/IAN/` after GitHub Pages finishes deploying.
